# Пять минут

Анонимная записка, которая живёт пять минут. Статическая страница для GitHub Pages — без бэкенда, аккаунтов и трекинга.

**Сайт:** https://ste4ik.github.io/five-minutes/

## Как это работает

1. Текст сжимается (`deflate-raw`) и шифруется AES-256-GCM прямо в браузере.
2. Ключ и шифротекст кладутся во fragment URL — часть после `#`, которую браузер никогда не отправляет на сервер.
3. GitHub Pages отдаёт только пустую страницу: ни текста, ни ключа он не видит.
4. Внутрь записки записаны время создания и срок жизни. Когда срок кончается, страница стирает текст из DOM и адресную строку.

Ссылка — это и есть хранилище. Восстановить записку из репозитория или на сервере невозможно: там её нет.

## Ограничения

- **Нет серверного удаления.** Пока срок не истёк, любой владелец ссылки может открыть записку снова. «Сжечь сейчас» стирает текст только в текущей вкладке.
- **Получатель может обойти таймер** — расшифровать полезную нагрузку вручную до истечения срока. Это защита от небрежности, а не от целенаправленного получателя.
- **Только текст, до 8 КБ.** Данные живут в URL, поэтому большие файлы не пролезут. Ссылки длиннее 4096 знаков мессенджеры могут обрезать — страница предупреждает об этом.
- **Срок отсчитывается от создания**, а не от первого открытия.
- Проверка срока идёт по локальным часам: сильно расходящиеся часы у отправителя и получателя дадут расхождение.

## Разработка

Один файл `index.html` — без сборки и зависимостей.

```sh
python -m http.server 8000
# открыть http://localhost:8000
```

Web Crypto требует secure context: `localhost` считается безопасным, обычный `http://192.168.x.x` — нет.

Деплой — GitHub Pages из ветки `main`, корень репозитория (Settings → Pages).
